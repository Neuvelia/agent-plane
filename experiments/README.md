# Experiment and development measurements

This directory is for structured measurements useful for the thesis and for evaluating the development workflow.

Do not store secrets, raw private repository content, or model hidden reasoning here.

## `run-log.csv`

One row can represent one Codex-assisted development feature/session summary.

The initial columns are intentionally simple and can evolve through a versioned export later.

Suggested workflow:

1. Complete/review a feature.
2. Record observable development metrics.
3. Keep subjective notes separate from measured values.
4. Do not turn missing values into zero; leave them empty or use an explicit unknown marker during analysis.
