# Third-party visual assets

The desktop UI bundles these local assets. Their full license texts are in
`licenses/` and must be included in packaged distributions.

| Asset | Version | Purpose | License |
| --- | --- | --- | --- |
| Inter (`@fontsource/inter`) | 5.3.0 | UI typeface | SIL Open Font License 1.1 (`licenses/Inter-OFL.txt`) |
| Lucide React (`lucide-react`) | 1.60.0 | UI icons | ISC (`licenses/Lucide-ISC.txt`) |

The original reference PDF supplied no reusable font or icon files. These
substitutes are the approved local visual variant; the PDF remains the source
reference for layout and geometry.
