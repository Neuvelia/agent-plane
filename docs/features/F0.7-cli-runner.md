# F0.7 - CLI runner

**Status:** implemented
**Priority:** P0
**Target phase:** Phase 0 - Execution Core

## Problem

The execution core needs a developer-facing interface before the visual IDE exists, and CI needs deterministic exit status and machine-readable output.

## Goal

Provide a minimal CLI for graph validation and execution.

## Commands

Target shape:

```text
agentplane graph validate PATH
agentplane run PATH --input key=value
agentplane run PATH --json
agentplane run PATH --watch
agentplane version
```

Exact flag names may be refined during planning.

## Functional requirements

1. Validation command exits 0 for valid graph and non-zero for invalid graph.
2. Run command validates before execution.
3. Human-readable mode shows node status and useful failures.
4. Machine-readable mode returns a stable JSON result envelope.
5. Process exit code reflects graph success/failure.
6. CLI presentation must not become the source of runtime state; it consumes runtime contracts/events.
7. `--watch` presents F0.6 events while the run executes, including node and stream identity for logs.
8. CLI users can apply F0.6 log redaction using values of named local environment variables.

## Acceptance criteria

- [x] Example parallel graph can be validated from CLI.
- [x] Example parallel graph can be run from CLI.
- [x] The three-node example's dependent output contains values supplied by both independent branches.
- [x] Invalid graph exits non-zero before executing a process.
- [x] Failed shell node makes the run command exit non-zero.
- [x] `--json` output can be parsed independently.
- [x] `--watch` shows node lifecycle events before the run completes.
- [x] A named environment value can be redacted from event logs.
- [x] Human-output write failure returns an internal CLI error status.
- [x] A broken CLI output pipe returns the internal error status; a live watch write failure cancels the active Shell child.
- [x] Unblocked watch output includes the cancellation terminal event.
- [x] `make check` passes.

## Required tests

- validation exit codes;
- successful run exit code;
- failed run exit code;
- JSON output parseability;
- live watch output and event order;
- built-CLI data flow through the dependent node;
- missing file/actionable error;
- human-output write failure;
- built-CLI broken-pipe exit status and active-child cancellation;
- cancellation terminal presentation.

## Out of scope for this iteration

- interactive TUI;
- local web server;
- run history database;
- cloud authentication;
- remote execution.
