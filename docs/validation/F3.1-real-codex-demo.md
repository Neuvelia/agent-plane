# F3.1 real Codex demonstration (isolated scoped retry)

Status: executed once on 2026-11-17, PASS. Recipe and recorded result below.

This is the F1.7 scoped-retry scenario (`docs/examples/scoped-retry.yaml`) with
`isolation: worktree` on every unit, run with a real installed Codex CLI in a
disposable repository. It checks what deterministic tests with a fake adapter
cannot: that real Codex, in its `workspace-write` sandbox, can produce an
accepted unit inside a linked worktree whose Git metadata lives in the source
`.git`, and that the whole F3.1 path (prepare, attempts, snapshot, integrate,
release) works end to end through the built CLI.

What a real run adds to the tests: bad -> red -> correct within three attempts
for unit C, A/B/D invoked once each, every accepted unit integrated into the
run's integration ref, the source checkout untouched, and no
`source_workspace_changed` fact. What it does not prove: model obedience in
general (nondeterministic, one run), the conflict path, or a correction attempt
that writes to a sibling's file path; those are covered by
`TestIsolationScopedRetryProtectsAcceptedSiblingFiles` and
`TestIsolationRealConflictKeepsTipAndRetainsTheWorktree`.

## Safety

The recipe sends only a freshly created disposable Git repository to the model.
It never points at the AgentPlane checkout or any real project. The graph
references only `HOME` and `PATH` for the CLI's existing authentication; no
secret is written to the graph, result or this record. Keep `result.json`,
`stderr.txt`, the graph and the worktree root inside the disposable directory
and do not paste raw provider output elsewhere. The run may consume model
quota. Do not add writable roots or bypass flags to make it pass.

## Preconditions

- An installed, authenticated Codex CLI; `CODEX_BIN` is its absolute path.
- Linux or macOS, `/usr/bin/git` 2.38 or newer (`merge-tree --write-tree`),
  Go and `python3`.
- Run from the repository root of a built or buildable AgentPlane checkout.

## Recipe

```sh
export CODEX_BIN=/absolute/path/to/installed/codex
DEMO_DIR=$(mktemp -d /tmp/agentplane-f31-demo.XXXXXX)
mkdir "$DEMO_DIR/repo"
git -C "$DEMO_DIR/repo" init -q
printf 'green\n' > "$DEMO_DIR/repo/expected.txt"
for unit in a b c d; do printf 'initial\n' > "$DEMO_DIR/repo/$unit.txt"; done
git -C "$DEMO_DIR/repo" add .
git -C "$DEMO_DIR/repo" -c user.name=AgentPlaneDemo \
  -c user.email=demo@example.invalid commit -qm baseline
python3 - "$DEMO_DIR" <<'PY'
import json, pathlib, sys
base = pathlib.Path(sys.argv[1])
root = str((base / 'repo').resolve())
t = pathlib.Path('docs/examples/scoped-retry.yaml').read_text()
t = t.replace('"__WORKSPACE__"', json.dumps(root))
t = t.replace('      adapter: codex\n', '      adapter: codex\n      isolation: worktree\n', 1)
(base / 'graph.yaml').write_text(t)
PY
go build -o "$DEMO_DIR/agentplane" ./cmd/agentplane
"$DEMO_DIR/agentplane" graph validate "$DEMO_DIR/graph.yaml" --json > "$DEMO_DIR/validation.json"
cd "$DEMO_DIR"
timeout 1200 ./agentplane run graph.yaml --adapter codex --codex-bin "$CODEX_BIN" \
  --input reference=expected.txt --max-concurrency 4 \
  --worktree-root "$DEMO_DIR/worktrees" --retain-worktrees failed --json \
  > result.json 2> stderr.txt
echo "exit=$?"
python3 - "$DEMO_DIR" <<'PY'
import collections, json, pathlib, subprocess, sys
base = pathlib.Path(sys.argv[1])
repo = base / 'repo'
r = json.loads((base / 'result.json').read_text())
assert r['cli_schema_version'] == 1 and r['status'] == 'succeeded', r.get('failure')
events = r['events']
assert all(e['event_schema_version'] == 11 for e in events)
attempts = collections.Counter(e['node_id'] for e in events if e['type'] == 'attempt_started')
assert attempts == {'a': 1, 'b': 1, 'd': 1, 'z_c': 2}, attempts
returns = [e for e in events if e['type'] == 'return_envelope']
assert [e['payload']['verdict'] for e in returns if e['node_id'] == 'z_c'] == ['red', 'green']
iso = r['workspace_isolation']
assert [u['node_id'] for u in iso['units']] == ['a', 'b', 'd', 'z_c']
assert all(u['integrated'] for u in iso['units']) and not iso['retained']
assert sum(e['type'] == 'workspace_prepared' for e in events) == 4
assert sum(e['type'] == 'workspace_integrated' for e in events) == 4
assert not [e for e in events if e['type'] in ('workspace_conflict', 'source_workspace_changed')]


def git(*args):
    return subprocess.run(['/usr/bin/git', '-C', str(repo), *args], check=True,
                          capture_output=True, text=True).stdout


for unit in 'abcd':
    assert git('show', iso['integrated_commit'] + ':' + unit + '.txt') == 'green\n', unit
    assert (repo / (unit + '.txt')).read_text() == 'initial\n', unit
assert git('rev-parse', 'HEAD').strip() == iso['base_sha']
assert git('status', '--porcelain') == ''
assert not list((base / 'worktrees').iterdir())
print('PASS', r['run_id'], r['graph_version'], dict(attempts))
PY
```

Unit IDs are `a`, `b`, `d` and `z_c` (logical C); `units` is unordered and the
IDs follow the scheduler's stable node order. The only change from the F1.7
graph is the `isolation: worktree` line the script inserts into the shared
Agent config, which is why every unit gets its own worktree. The embedded
command Gate compares files relative to its `cwd`; the runtime points that
`cwd` at the unit's worktree (a fix made while preparing this demo, see
`TestIsolatedNodeRepointsGateWorkspaceAndCwdWithoutMutatingTheGraph`).

Reading a failure: a failed assertion is evidence to investigate. Inspect
`result.json` (events and `workspace_isolation`), then `git -C "$DEMO_DIR/repo"
worktree list` and the retained paths in the result. If Codex could not run
(authentication, quota, network), that is an environment problem, not a verdict.
Clean up by deleting `$DEMO_DIR` after `git -C "$DEMO_DIR/repo" worktree prune`
if anything was retained.
