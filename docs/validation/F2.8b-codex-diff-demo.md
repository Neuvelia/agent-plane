# F2.8b real-Codex attempt diff demo (recipe, not yet executed)

Status: recipe only. The engine capture is proved with temporary Git repositories
and a fake Codex (ADR-0026, `docs/features/F2.8-attempt-compare.md`). Run this once
against an installed Codex and record the result here.

1. Create a throwaway Git repository with one commit and a file `a.txt`.
2. Write a one-node loop Agent graph (`max_attempts: 2`) whose Gate fails the first
   attempt (for example a `command` Gate that requires a marker file the task creates
   only when told) and passes the second; set `workspace` to the repository.
3. Export a dummy secret (`export AP_DEMO_SECRET=...`) and put it in the task text so the
   agent may echo it into a file.
4. Run:
   `agentplane run graph.yaml --adapter codex --codex-bin /abs/codex --record-diffs --redact-env AP_DEMO_SECRET --store-dir ./store --json`
5. Check: each attempt has `attempt_diff` file events followed by a summary between
   `node_evidence` and `attempt_finished`; attempt 2 holds only attempt-2 changes; no
   occurrence of the secret in the output or `./store/*/events.jsonl`; `$TMPDIR` holds no
   `agentplane-diff-*` directory after the run; `git status` shows only what Codex changed.
6. Record Codex version, date, the commands and the observed event summary below.
