# Historical implementation plans and design notes

`plans/` and `specs/` hold dated working plans and design notes written while
features were implemented. They are **historical**: their checkboxes were not
kept up to date and they are **not a source of feature status**.

Current contracts live in `docs/features/` (feature specs) and `docs/adr/`
(decisions). Feature status is tracked as described in `docs/roadmap/`
(see `docs/roadmap/audit/` for the latest audit).
